# QGIS quick start

1. Open `data/processed/county_priority_scores.gpkg` in QGIS.
2. Select the `priority_scores` layer.
3. Open **Layer Properties → Symbology → Style → Load Style**.
4. Choose `gis/priority_score.qml`.

The style uses five transparent score bands. Keep the source note and the screening-only interpretation visible in any exported map.
